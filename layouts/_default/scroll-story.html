The challenge

Three dashboards.
Years of technical debt.

Three separate internal products — built at different times, by different teams, on different stacks — had drifted into visual and functional chaos. Engineers spent more time matching inconsistent UI than building features. Support tickets rolled in every sprint.

The goal: one unified design system, deployed across all three products, with zero framework lock-in and a first-load budget under 2 seconds.

How we got there

Token-driven.
Zero framework dependencies.

Rather than wrapping everything in a heavy component library, we built the system on a foundation of CSS custom properties — a single set of design tokens that every product imported. Components were plain HTML + CSS. No runtime overhead, no build coupling.

Execution

Six months.
Zero downtime.

Migration happened incrementally — one product at a time — with a shared token layer ensuring visual parity from day one. No big-bang rewrite. Engineering teams kept shipping features throughout the transition.

Inclusion by design

WCAG AA.
Every view.

Accessibility wasn't a checklist item — it was a token-level constraint. Color contrast ratios, focus rings, keyboard navigation, and ARIA patterns were built into the system itself, not bolted on afterward. Every component ships AA-compliant out of the box.
